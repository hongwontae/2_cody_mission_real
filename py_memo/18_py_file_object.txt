1. open으로 파일을 읽어들이면 파일 객체가 전달됩다.
    
    ⇒ 실제 파일에 접근하기 위한 Python 객체입니다.
    
    ⇒ Python이 파일을 다루기 위해 만들어 놓은 객체
    

2. 구조
    
    2-1. 디스크에 실제 파일이 존재 (test.txt라고 가정)
    
    2-2. Python 프로그램에서 open 호출
    
    2-3. OS에게 디스크에 존재하는 파일인 test.txt 열어달라고 요청
    
    2-4. OS가 파일을 찾음
    
    2-5. OS가 test.txt를 사용하기 위한 열린 파일 상태를 커널 내부에 만듭니다.
    
    ⇒ 프로세스가 파일을 열어서 사용하고 있다는 OS 내부의 관리 정보를 만듭니다.
    
    2-6. 다음으로 OS가 파일 디스크립터를 하나 줍니다.
    
    ⇒ 이 열린 파일을 식별할 수 있게 번호 하나
    
    2-7. 다음으로 OS가 Python에게 파일을 가리키는 번호를 줘서 이 정보를 토대로 Python 파일 객체 생성
    
    2-8. f.read() | f.write()를 하면 파일 디스크립터 번호를 가지고 OS에게 요청
    
    ```c
    test.txt (디스크에 실제 존재)
            ↑
            │
       운영체제의 파일
            ↑
            │
    Python의 파일 객체 f
    ```
    
    ```c
    커널 메모리
    
    ┌──────────────────────────┐
    │ 열린 파일 정보            │
    │                          │
    │ 파일 위치: 0             │
    │ 접근 모드: 읽기(r)       │
    │ 기타 파일 상태 정보       │
    │                          │
    │ → 실제 test.txt를 가리킴 │
    └──────────────────────────┘
    ```
    
    ```c
    ┌─────────────────────┐
    │ Python 파일 객체     │
    │                     │
    │ fd = 3              │
    │ read()              │
    │ write()             │
    │ seek()              │
    │ close()             │
    │ 기타 Python 정보    │
    └──────────┬──────────┘
    ```
